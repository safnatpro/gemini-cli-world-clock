# World Clock for Gemini CLI

Two small tools, no dependencies and no network access:

- `current_time` — the current date and time in any IANA timezone
- `convert_time` — convert an ISO-8601 timestamp into another timezone

## Install

```bash
gemini extensions install https://github.com/safnatpro/gemini-cli-world-clock
```
